# Santhiya P. S.

Personal academic website, built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) remote theme (skin: `dark2`) and hosted on GitHub Pages.

- `index.md`: home page
- `_pages/`: About, Research, CV, Photography
- `_data/navigation.yml`: top navigation
- `files/cv.pdf`: CV linked from the site
- `_config.yml`: site and author settings
